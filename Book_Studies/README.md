# Christian Book Studies Hub | 基督教书籍研读中心

> Reading guides for influential Christian books. Each guide identifies the book’s own argument, distinguishes historical and scientific evidence from theological conviction, and avoids treating a secondary guide as a replacement for the original book.
>
> 本区收录有影响力的基督教书籍研读指南。每份指南都会辨明原书论证，区分历史／科学材料与神学信念，也不会把二手导读当成原书的替代品。

## Reading Method | 阅读方法

1. **Read the original chapter first.｜先读原书章节。** Record the author’s actual claim before consulting the guide.
   先记录作者真正提出的论点，再查看导读。
2. **Identify the claim type.｜辨认论证类型。** Separate biblical interpretation, theology, philosophy, history, manuscripts, natural science, testimony, and application.
   区分释经、神学、哲学、历史、抄本、自然科学、见证与应用。
3. **Check the evidence appropriate to that claim.｜按主张类型核查证据。** A testimony should not be judged as a laboratory experiment, and scientific or historical claims should not be insulated from current evidence merely because they appear in a devotional book.
   见证不应被当成实验室报告来判断；科学或历史主张也不能因为出现在属灵书籍中就免于当代证据核查。
4. **State support and limits together.｜同时写出支持与边界。** Explain what a citation establishes and what remains interpretation or faith commitment.
   说明引用材料能够建立什么，以及哪些部分仍属于解释或信仰委身。
5. **Return to the author’s central question.｜回到原书核心问题。** Do not let side disputes erase the book’s main spiritual or theological burden.
   不要让支线争议遮蔽原书真正要处理的属灵或神学负担。

## Guide Standards | 导读标准

A whole-book guide should include a bilingual title, edition or scope note, an accurate overview in both languages or a clearly labeled orientation, a chapter or argument map, evidence boundaries, and a route back to Scripture or primary sources.

全书导读应包含双语标题、版本或范围说明、双语概览或明确标注的另一语言导读、章节／论证地图、证据边界，以及返回经文或一手来源的路线。

Do not invent a table of contents that is not publicly verifiable, reproduce substantial copyrighted text, or present the guide as if it were the book itself. When editions differ, state which edition or public structure the guide follows.

不得虚构无法公开核实的目录，不得大量复制受版权保护的正文，也不得把导读写成原书本身。不同版本若有差异，必须说明导读依据的版本或公开结构。

## Add a New Book Study | 新增书籍研读

- Link the new guide from this page and from the [Master Index｜总索引](../INDEX.md).
- Record the original work’s language separately from the guide’s language status.
- Prefer primary publisher, author, library-catalog, or edition records for bibliographic facts.
- Run `python3 scripts/audit_markdown.py` from the repository root.

- 把新导读加入本页和[总索引](../INDEX.md)。
- 分开记录原书语言与仓库导读的语言状态。
- 书目信息优先使用出版社、作者、图书馆目录或版本记录等一手来源。
- 在仓库根目录运行 `python3 scripts/audit_markdown.py`。
