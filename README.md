## About This Library | 关于本资料库

Project Covenant combines biblical theology, historical context, manuscripts, and archaeology, and says what each kind of evidence can and cannot show. AI helps draft, organize, and translate it, and every page is still a Draft that has not been reviewed by a person.<br>
Project Covenant 结合圣经神学、历史语境、抄本和考古材料，并说明每类证据能支持什么、不能支持什么。资料由 AI 辅助起草、整理和翻译；所有页面仍是 Draft，尚未经过人工审阅。

Page content does not include the maintainer's personal experiences, testimony, church attendance records, or contact information. Source churches are described only in general terms.<br>
页面内容不包含维护者的个人经历、见证、聚会出席记录和联系方式。来源教会只以泛称描述。
