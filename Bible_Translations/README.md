## What This Section Stores | 本区保存什么

- Official acquisition links and version metadata.
- Reading-use profiles, including where a translation may help English learners.
- Comparison methods for passages whose wording affects interpretation.
- Copyright, permission, and repository-storage boundaries.

- 官方获取入口与版本资料。
- 阅读用途定位，包括译本怎样帮助英语学习者。
- 当措辞影响解释时的译本比较方法。
- 版权、许可与仓库存储边界。

This section does **not** mirror complete copyrighted Bible texts, application installers, proprietary modules, or private downloads. Personal offline files should remain outside Git or under an ignored private-download directory.

本区**不镜像**受版权保护的整本圣经文本、应用安装包、专有模块或私人下载文件。个人离线文件应保留在 Git 之外，或放入已被忽略的私人下载目录。

## How to Use a Translation with This Library | 怎样配合本资料库使用译本

1. **Read the biblical passage itself.｜先读经文本身。** Mark speakers, setting, repeated words, and literary movement.
   标记说话者、处境、重复词与文脉推进。
2. **Locate it in the storyline.｜放回故事线。** Use the [Bible Timeline Overview｜圣经时间线总览](../Bible_Timeline/Bible_Timeline_Bilingual.md) or [Bible by Book｜按书卷梳理圣经](../Bible_Timeline/Bible_By_Book_Bilingual.md).
   使用[圣经时间线总览](../Bible_Timeline/Bible_Timeline_Bilingual.md)或[按书卷梳理圣经](../Bible_Timeline/Bible_By_Book_Bilingual.md)定位。
3. **Compare only when wording matters.｜在措辞重要时再比较。** Ask whether a difference reflects English style, textual variants, or an interpretive decision.
   判断差异来自英文表达、文本异文，还是解释选择。
4. **Consult notes and source-language scholarship for serious disputes.｜重大争议应查注释与原文研究。** No single English preference should carry an entire theological conclusion.
   不应仅凭偏好的英文措辞建立完整神学结论。
5. **Respect the license.｜遵守授权。** Check quotation limits and permissions before copying, publishing, or redistributing text.
   复制、出版或转发经文前，应核对引用限额与许可规则。

## Translation-Guide Standard | 译本导读标准

A translation guide should identify the publisher or rights holder, official access routes, stated translation approach, intended readers, practical strengths, limitations, comparison advice, and copyright terms. Recommendations must distinguish publisher claims from independent testing or the reader’s own experience.

译本导读应说明出版方或权利人、官方获取入口、公开翻译理念、目标读者、实际优势、限制、比较建议与版权条款。推荐时必须区分出版方自述、独立测试与读者个人体验。

External app availability, price, platform support, and license terms can change. Update guides from official sources rather than copying stale download instructions into multiple files.

外部应用可用性、价格、平台支持与授权条款可能变化。更新导读时应核对官方来源，不要在多个文件中重复复制容易过期的下载说明。

## Add a Translation Guide | 新增译本导读

- Link the guide from this page and the [Master Index｜总索引](../INDEX.md).
- Record the guide’s language status separately from the translation’s source languages.
- Do not commit a complete copyrighted translation without explicit written permission.
- Run `python3 scripts/audit_markdown.py` from the repository root.

- 把导读加入本页和[总索引](../INDEX.md)。
- 分开记录仓库导读的语言状态与译本原文语言。
- 未取得明确书面授权时，不得提交受版权保护的完整译文。
- 在仓库根目录运行 `python3 scripts/audit_markdown.py`。
